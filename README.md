# ritvi-apps.github.io

The Ritvi Apps landing page, served at <https://ritvi-apps.github.io/>.

Exists so the Play and App Store listings can point at a business website
instead of a personal one. The developer website field on the Charades listing
pointed at `riteshf.deno.dev` — a personal domain — which is what this replaces.

`ritvi-apps/legal` keeps serving at `/legal`; org pages (this repo) and project
pages coexist.

## Deploy

GitHub Pages, branch `main`, root. No build step.
