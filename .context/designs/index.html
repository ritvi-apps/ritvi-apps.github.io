What was wrong

This domain is the developer website on every Play and App Store listing. That is its job. The live version is a single 5KB page with four cards and no icons and no screenshots anywhere.

Three of the four cards are dead <div>s labelled "Coming soon" — while Imposter has an open Android beta and Aakalan has an open TestFlight, both already recorded in the portfolio's profile.json. Charades' iOS TestFlight is not shown either. Working install links existed and were not used.

There is no page per app, so every store listing, privacy link and support route points at the same generic page and the click is wasted. And "How we build" sits above the apps — the values before the thing anyone arrived for.

The three rules this set is built on

1 · Every app has a page, and every page has a Get block. The same three destinations in the same order every time — the app's own site, App Store, Google Play. A destination that does not exist renders disabled with the reason beside it, never hidden: "no build uploaded yet" is information, a missing button is a dead end.

2 · Availability is never a euphemism. Live · Beta open · Closed testing · Coming. If an app has a join link, the card says Beta open and links to it. "Coming" is reserved for an app nobody can install — which, today, is AskCal alone.

3 · Show the app. Icon and screenshots on every card and every page, reusing the same assets as the store listings so the two can never disagree.

Open questions for you

The app websites. The Get block's first destination assumes a per-app domain (charades.ritvi.app and so on). If those do not exist, that button should point back at the app's page here instead — say which and the designs change in one place.

The support address. The screens keep firodiya.ritesh@gmail.com, since a prior commit deliberately reverted to the personal address on the listings. A support@ alias is a one-line change if you now want one.

Tic Tac Toe's bundle id is com.riteshf.tictactoe, not com.ritvi.* — it is listed here as a Ritvi app anyway. Tell me if it should not be.

What is deliberately not here

Real assets. Every icon and screenshot is a labelled placeholder — roughly 40 slots. Most already exist in the app repos' .context/store/ folders and can be copied in rather than made.

Any shipped HTML. The live index.html is untouched. That starts after these are approved.
